# TOTP 工具 计划7：图标系统 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付完整图标体系：内置品牌图标集（Simple Icons 精选 + issuer 别名映射推荐）、aegis-icons 风格图标包导入（zip）、用户上传、HTTP URL 引用（拉取缓存），条目列表与录入表单全面接入。

**Architecture:** core 新增 `IconRef` 模型与内置图标注册表（路径数据 JSON 随包发布，simple-icons devDep 提取脚本生成）+ issuer 归一化推荐查找；ui 新增 `createIconStore(adapter)`（'icons' 键，dataUrl 映射，双端复用既有 StorageAdapter）、zip 包导入（fflate）、上传缩放（canvas）、URL 拉取缓存、EntryForm 图标推荐气泡、OtpListItem 图标渲染。条目通过 `icon?: IconRef` 引用。

**Tech Stack:** fflate（zip 解包，ui 包运行时依赖）、simple-icons（core devDependency，仅提取脚本用）、canvas（jsdom 环境上传缩放以浏览器为准，单测 mock）。

**Spec:** `docs/plans/2026-09-13-totp-tool-design.md`（第 8 节图标系统）

## Global Constraints

- 沿用全部既有约束（TS strict、TDD、Angular commit、中文 UI、core 运行时依赖仅 hash-wasm——simple-icons 与 fflate 分别是 core devDep 与 ui 运行时依赖，合规）
- `IconRef = { kind: 'builtin'; id: string } | { kind: 'stored'; id: string } | { kind: 'url'; id: string; url: string }`（id 均 uuid 或内置名；url 拉取成功后缓存为 stored，保留 url 供刷新）
- 内置集规模：精选 64+ 品牌（脚本从 simple-icons 提取 path 数据生成 `packages/core/src/icons/builtin.json` 随包提交；覆盖 GitHub/GitLab/Google/Microsoft/Apple/Amazon/Steam/Discord/Slack/Cloudflare/AWS/Bitbucket/Stripe/PayPal/Twitter/X/Reddit/YouTube/Twitch/Netflix/Spotify/SteamChat 等，脚本内置名单）
- 别名映射：`normalizeIssuer(name)`——小写、去空白/点/连字符；推荐查找顺序：精确 id 匹配 → 别名表（含 github.com→github、谷歌→google 等中英别名，脚本内置）→ 无
- 图标数据统一 dataUrl（PNG/JPEG/SVG data URL）；上传缩放至 ≤128×128（保持比例，canvas）
- 图标存储：'icons' 键 = `Record<string, string>`（id→dataUrl），经既有 StorageAdapter（extension chrome.storage.local + unlimitedStorage 权限；desktop AppData icons 键）
- 涉及 manifest/wxt 配置必须核对构建产物

**Interfaces:**
- Produces:
  ```ts
  export type IconRef = { kind: 'builtin'; id: string } | { kind: 'stored'; id: string } | { kind: 'url'; id: string; url: string }
  export interface BuiltinIcon { id: string; title: string; path: string }  // path: Simple Icons 24x24 path data
  export function getBuiltinIcons(): Record<string, BuiltinIcon>
  export function normalizeIssuer(name: string): string  // 小写+去空白/点/连字符/下划线
  export function recommendBuiltinIcon(issuer: string): BuiltinIcon | null  // normalize 后精确 id → 别名表 → null
  export function suggestIcons(issuer: string, limit?: number): BuiltinIcon[]  // 前缀包含匹配（normalize 后 includes），默认 5
  ```
- 脚本：从 simple-icons 包 `require('simple-icons')`（`si<Name>` 对象含 path/title/slug）提取内置名单生成 builtin.json 与别名表（脚本内 `ALIASES: Record<string,string>`：如 'githubcom'→'github'、'谷歌'→'google'、'steamchat'→'steam' 等，至少 30 条中英别名）
- model.ts：`import type { IconRef } from './icons/registry'` + OtpEntry 加 `icon?: IconRef`

import { describe, expect, it } from 'vitest'
import { getBuiltinIcons, normalizeIssuer, recommendBuiltinIcon, suggestIcons } from '../src/icons/registry'

describe('iconRegistry', () => {

- Create: `packages/ui/src/iconStore.ts`
- Modify: `packages/ui/src/index.ts`
- Test: `packages/ui/test/iconStore.test.ts`

**Interfaces:**
- Produces:
  ```ts
  export interface IconStore {
    icons: Readonly<Record<string, string>>       // reactive
    init(): Promise<void>                          // 幂等：读 'icons' 键填充
    put(id: string, dataUrl: string): Promise<void>
    remove(id: string): Promise<void>
    resolve(ref: IconRef | undefined): string | undefined  // builtin→undefined（组件直接用 path 渲染）/stored→icons[id]/url→icons[url:id] 缓存
    fetchAndCache(ref: { kind: 'url'; id: string; url: string }): Promise<string | null>  // fetch(url)→blob→FileReader dataURL→put；失败 null
  }
  export function createIconStore(adapter: StorageAdapter): IconStore
  ```
- 内部：模块级 'icons' 键；reactive map；put/remove 写内存+防抖 300ms 落盘（参考 store 模式但图标写不频繁——直接直写亦可，取简单者报告说明）；fetch 用全局 fetch（extension 页面 CORS 限制如实接受，失败返回 null）

**Interfaces:**
- Produces:
  ```ts
  export interface IconPackResult { imported: number; skipped: number; names: string[] }
  export async function importIconPackZip(zipBytes: Uint8Array, icons: IconStore, opts?: { max?: number; maxBytes?: number }): Promise<IconPackResult>
  // aegis-icons 结构：任意层级下 *.png，文件名（去扩展名）为 issuer 名 → recommendBuiltinIcon 兜底查 id，否则 normalizeIssuer 作 stored id；跳过非 png/超过 maxBytes(默认50KB)/超过 max(默认500) 个；同名（normalize 后）后者覆盖前者并计 skipped
  export async function fileToScaledDataUrl(file: Blob, size?: number): Promise<string>  // canvas 缩放 ≤size(128) 保持比例，PNG 输出
  ```
- jsdom 无 canvas：fileToScaledDataUrl 的测试以「jsdom 缺 canvas API 时抛 Error('canvas 不可用')」行为锚定（真实缩放在浏览器手工验收）——`document.createElement('canvas').getContext` 为 null 时抛中文错误
