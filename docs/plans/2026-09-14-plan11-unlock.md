# TOTP 工具 计划11：passkey PRF / DPAPI 解锁 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** KEK 第三/四种来源：Passkey + WebAuthn PRF extension（本地验证即派生 KEK 自动解锁，绑定 Windows Hello/PIN/Touch ID 等）与桌面端 Windows DPAPI/凭据管理器（开机静默解锁）。与既有口令模式并存（多绑），密码学基础复用 P6 securityStore 分层（DEK 不变，KEK 来源扩展）。

**Architecture:** core `security/` 扩展：SecuritySettings 的 KEK 来源结构化（`kekSources: Array<{kind:'password'} | {kind:'prf', credentialId, salt} | {kind:'dpapi', wrapped}>`）——**关键设计**：现 wrappedDek 由口令 KEK 包裹；多绑=同一 DEK 被多把 KEK 分别包裹成多个 wrapped blob。PRF：WebAuthn get() with extensions prf，derive出 32B KEK（PRF 输出直接作 KEK，盐=固定随机 salt 存 settings）；DPAPI（仅桌面）：Rust 命令 CryptProtectData 包裹随机 KEK2——**DPAPI 语义：随机 KEK_dpapi 生成后 CryptProtectData 存 settings，解锁时 CryptUnprotectData 取回**。ui：解锁方式管理 UI（SecurityCard 扩展：添加 passkey/启用 DPAPI/移除）；LockScreen 支持多方式选择。

**Tech Stack:** WebAuthn（浏览器原生）、tauri Rust `windows` crate（已依赖，计划 5 P5 引入过 CryptUnprotectData——T3 WinAuth 用过，复用）。

**Spec:** `docs/plans/2026-09-13-totp-tool-design.md`（第 7 节密钥分层：passkey PRF 与 DPAPI 两种 KEK 来源）

## Global Constraints

- 沿用全部既有约束；PRF 仅扩展环境与桌面（WebView2）支持——Firefox 对扩展页面 PRF 支持有限，**运行时探测，不支持则 UI 隐藏该选项并说明**
- SecuritySettings v1 → v1 兼容扩展：新增可选 `kekSources?: KekSource[]`（缺省视为 [{kind:'password'}]；wrappedDek 字段保留为口令包裹——迁移语义：旧 settings 读取时 kekSources=[{kind:'password'}]）；每种 KEK 来源的 wrapped blob：`wrappedDekP: string`（prf）、`wrappedDekD: string`（dpapi，CryptProtectData 输出 base64）
- PRF salt：随机 32B，存于 kekSources 条目；KEK_prf = PRF 输出第一 32 字节（webauthn prf evalResults first）
- DPAPI KEK：随机 32B KEK_dpapi → wrappedDekD = CryptProtectData(KEK_dpapi)；KEK_dpapi 仅为解 wrappedDekD 的中间钥？——**简化裁定：wrappedDekD = CryptProtectData(DEK)（DPAPI 直接包裹 DEK，无中间层）**；解锁=CryptUnprotectData(wrappedDekD) 得 DEK
- 移除口令来源（仅 passkey/dpapi 存在时）需先确认仍有其余解锁方式；至少保留一种
- 涉及 Rust/manifest 的产物核对照旧

**Interfaces:**
- Produces:
  ```ts
  export type KekSource = { kind: 'password' } | { kind: 'prf'; credentialId: string; salt: string; wrappedDekP: string } | { kind: 'dpapi'; wrappedDekD: string }
  export function kekSourcesOf(s: SecuritySettings): KekSource[]  // 归一：缺省/空→[{kind:'password'}]
  export function withPrfSource(s: SecuritySettings, credentialId: string, salt: string, wrappedDekP: string): SecuritySettings
  export function withDpapiSource(s: SecuritySettings, wrappedDekD: string): SecuritySettings
  export function removeKekSource(s: SecuritySettings, kind: 'prf' | 'dpapi' | 'password', match?: { credentialId?: string }): SecuritySettings  // password 移除时需 kind!=='password' 或移除后仍剩 ≥1 来源，否则抛 Error('至少保留一种解锁方式')
  export function unlockWithPrf(s: SecuritySettings, prfOutput: Uint8Array): Promise<Uint8Array>  // 找 prf 源→KEK=prfOutput前32B→解 wrappedDekP→DEK；找不到/解不开→Error('passkey 解锁失败')
  ```
